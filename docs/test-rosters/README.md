# 排座规则测试数据集

每个文件均为 UTF-8 BOM CSV/TXT，可直接通过学生名单导入对话框粘贴或上传，用于回归验证不同排座规则。

| 文件 | 字段 | 场景 | 验证规则 |
|---|---|---|---|
| 01-智慧教室-姓名性别均衡30人.csv | 姓名/性别 | 智慧教室 | 男女均衡 (15/15) 验证性别交错/集中策略 |
| 02-音乐厅-姓名性别40人.csv | 姓名/性别 | 音乐厅 | 20男20女验证一行男一行女间隔排列 |
| 03-宴会厅-姓名单位48人.csv | 姓名/单位 | 宴会厅 | 6单位×8人验证按单位集中分桌 |
| 04-教室智能集中-姓名性别单位36人.csv | 姓名/性别/单位 | 智慧教室 | 3班级×12人验证按班级集中 + 性别分布 |
| 05-完整字段-姓名性别单位职务30人.csv | 姓名/性别/单位/职务 | 通用 | 完整字段冒烟测试 |
| 06-高校班级-姓名性别单位职务48人.csv | 姓名/性别/单位/职务 | 高校 | 5学院带班委验证按学院集中 + 职务排序 |
| 07-极端-全男20人.csv | 姓名/性别 | 音乐厅 | 单一性别时规则降级行为 |
| 08-极端-男女悬殊30人.csv | 姓名/性别 | 音乐厅 | 25:5 验证性别比例失衡处理 |
| 09-极端-单位悬殊32人.csv | 姓名/单位 | 宴会厅 | 一个20人大单位 + 4个3人小单位 |
| 10-纯姓名换行40人.txt | 姓名 | 最小输入 | 仅姓名时回退为随机座位 |
| 11-姓名性别空格30人.txt | 姓名/性别 | 容错 | 空格分隔无表头解析 |
| 12-小班完整字段24人.csv | 姓名/性别/单位/职务 | 小班 | 与默认 24 人示例对齐 |
